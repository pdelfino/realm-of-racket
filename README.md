## About

This repository contains implementations and study notes for the book [Realm of Racket](https://www.realmofracket.com/) by Matthias Felleisen, David Van Horn, Conrad Barski, and others. The work was done as part of the *Linguagens de Programacao* (Programming Languages) course at FGV, taught by Professor Alexandre Rademaker, in the second semester of 2016.

The project was a collaboration between **Pedro Delfino** and **Daniel Wise**.

## Tech Stack

- **Racket v6**
- Notes written in **Org-mode** (Emacs)

## Key Topics Covered

- Unit testing with **RackUnit**
- Text-based games (Guess My Number -- both functional and imperative styles)
- Building graphical interfaces with Racket's GUI libraries
- Interactive games, including a **Snake** clone
- Reimplementing built-in functions (`member`, `foldr`, `build-list`)
- Lazy evaluation strategies
- Game AI (Dice of Doom)

## Repository Structure

All source material lives under the `source/` directory, organized by chapter. Files are a mix of `.org` (literate notes with embedded code) and `.rkt` (standalone Racket source files).

## Language Note

The study notes (`.org` files) are written in Portuguese, as this was coursework for a Brazilian university.
